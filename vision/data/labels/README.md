# HERO 车辆标注数据

## 文件

| 文件 | 说明 |
|---|---|
| `annotations.jsonl` | 每行一条标注，**只增不删**。字段见下。 |
| `ann-<时间>.jpg` | 标注时的那一帧原图（`ann-<id>` 与记录里的 `image` 一一对应）。 |
| `seed/` | 三张早期真实帧（车头朝左 / 朝右 / 朝上且位于画面右侧的失败帧），随仓库保存。 |

## 一条记录

```jsonc
{
  "id":       "ann-20261017-091155",
  "image":    "ann-20261017-091155.jpg",
  "from":     "http://192.168.3.118/stream",   // 或 vision/data/labels/seed/xxx.jpg
  "saved_at": "2026-10-17T09:11:55",
  "quad":     [[754,324],[750,400],[711,398],[716,322]],   // 拟合出的精确矩形
  "raw_quad": [[754,324],[749,401],[710,399],[717,321]],   // 人手实际点的位置
  "tip":      [760, 320],          // 车头方向（由 quad 自动推出；人工修正时 tip_source=manual）
  "tip_source": "auto",            // auto | manual
  "status":   "ok",                // ok | skip | invalid
  "notes":    ""
}
```

**约定**：`quad[0]` = 车的**右前角**，其余顺时针；因此 `quad[0]→quad[1]` 沿车身长边指向后方，
车头方向 = 从中心沿 −(quad[1]−quad[0])。矩形是拟合的（对边等长、四角 90°），
`raw_quad` 保留原始点击 —— 拟合不能反推回原始输入，所以两者都存。

坐标一律是图片像素，原点左上（与 `vision/src/contract.py:59` 同一个坐标系）；
角度 0° 沿 +x 向右，顺时针增大。
